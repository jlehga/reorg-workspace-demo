Either way, start with the live demo if you can.

────────────────────────────────────────────────────────────────
3. 60-SECOND DEMO PATH
────────────────────────────────────────────────────────────────
1. Sign in with demouser / test123
2. Workspace home → New Reorg Case
   (or Start from scenario → Scenario A → Load scenario text)
3. Submit tab → Analyze reorg
4. Review case → note unverified Finance approval warning
5. Plan & approve → Approve plan
6. Execute → Run execution → Mark complete on the GL task (CC-4175)
7. Reconcile → all Passed → case Completed
8. ← Back to workspace → case appears under Past cases
9. (Optional) Audit tab for the event trail

Optional failure beat: before Mark complete, check
“Simulate incorrect GL entry (demo failure path)” → reconciliation fails.
Optional Scenario B: load Scenario B for ambiguity / validation failures.

────────────────────────────────────────────────────────────────
4. IF THE LIVE DEMO IS UNAVAILABLE
────────────────────────────────────────────────────────────────
Unzip the attached reorg-execution-system.zip (or this archive), then:

  python -m venv .venv
  source .venv/bin/activate          # Windows: .venv\Scripts\activate
  pip install -r requirements.txt
  streamlit run app.py --server.port 8765
  # or: ./run_demo.sh

Open http://127.0.0.1:8765 and sign in with demouser / test123.
